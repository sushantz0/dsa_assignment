# Reverse Traversal of Linked List in C

## Overview

This program demonstrates **reverse traversal of a singly linked list** using recursion.  
It prints the elements of a linked list from the **last node to the first node** without modifying the original list.

---

## Features

- Supports singly linked lists of any size.
- Traverses the list in reverse order using recursion.
- Prints all elements in reverse order.
- Uses dynamic memory allocation for nodes.

---

## How It Works

1. Nodes are added to the linked list using `insertEnd()`.
2. `reverseTraversal()` recursively goes to the end of the list.
3. When the recursion unwinds, it prints each node’s data in reverse order.
